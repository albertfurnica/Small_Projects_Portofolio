# Interactive To-Do List (Blazor Web App)

A dynamic and interactive To-Do List application built to demonstrate frontend state management and C# logic directly in the browser using **Blazor**.

## 🚀 Features
* **Add Tasks:** Quickly add new tasks to the list.
* **Mark as Done:** Interactive checkboxes mapped to C# boolean properties to toggle task completion.
* **Delete Tasks:** Remove items from the list using Lambda expressions to handle specific item states.
* **Dynamic Sorting & Filtering:** Utilizes **LINQ** to automatically sort the list (e.g., moving completed tasks to the bottom) and count active tasks in real-time.

## 🛠️ Technical Details
* **Framework:** Blazor Server
* **Language:** C#, HTML, CSS
* **Key Concepts:** `@bind` for two-way data binding, `@onclick` event handling, LINQ for collections manipulation, and CSS Flexbox for responsive layout.
