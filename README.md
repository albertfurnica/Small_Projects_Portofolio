# .NET & Blazor Web Mini-Projects Portfolio

Welcome to my web development portfolio! This repository contains a collection of mini-projects and web applications built from scratch to demonstrate modern web architecture and backend logic.

## 💻 Technologies Used
* **Framework:** .NET 10, ASP.NET Core
* **Frontend:** Blazor (Server/WebAssembly), Razor Components, HTML, CSS
* **Backend Logic:** C#, LINQ (Language Integrated Query)
* **Architecture:** Component-based UI, State Management, Object-Oriented Programming (OOP)

## 📂 Repository Structure
Each folder in this repository represents a standalone project. Navigate to any specific folder to read its dedicated documentation and explore the source code.
